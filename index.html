Describe any business process with three elements.

Map how your business works without the complexity of BPMN. You arrange three kinds of element, and the diagram enforces one rule: processes interact only through documents.

View on GitHub Run it yourself
  • Process

    Something your business does with information.

  • Document

    The information itself: an order, an invoice, a form.

  • External process link

    A pointer to a process that lives outside this diagram.

Processes interact only through documents

In business terms, this means one thing: information has to flow between processes. The diagram enforces it, so a direct link from one process to another is not allowed.

What about goods, items, and shipments? Every physical object comes with a document, such as an invoice, an order, or another form. Model the document and the object is covered.

Describing a process takes three answers

  • Who

    Who works with the input information?

  • When

    When do the results need to be available?

  • What

    What is the essential action that turns the input into output information?

One script, one dependency

The program is a single Python script. It needs only PySide6 to run.

pip install PySide6
python main.pyw

Need a binary for a machine without Python? Build one with PyInstaller.

pip install pyinstaller
pyinstaller --onefile --windowed --icon process_diagram_editor.ico main.pyw
